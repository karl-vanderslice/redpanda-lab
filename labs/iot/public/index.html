Thresholds and recovery

Temperature limits are inclusive. Battery below the device threshold opens an alert. Only a subsequent safe reading clears an alert; elapsed time does not.

Sequences must increase per device; gaps are allowed. Unknown completion blocks new writes. Keep the exact ID and values, inspect state, then restart the app to replay before retrying. Topic history must remain intact.

The HTTP gateway writes iot.events.v1; KafkaJS rebuilds state. No MQTT, physical sensor calibration or notification service is connected.

# Folio Harbor Archives

An archival register for append-only commands and rebuilt state.

## Design

- Warm paper, cobalt actions and graphite dark surfaces. Georgia headings pair with system controls and tabular offsets.
- A narrow item index, command workspace and receipt inspector sit above the full-width event register. Small screens stack the same work areas.
- Color marks action and selection. Readiness, rejection and uncertain completion retain explicit labels.

Exact receipt lookup and prefix evidence are functional controls, not decorative archive labels.

## References

The taste-book references inform hierarchy and surface treatment. No source image, logo, font or component is copied. Authored colors are not sampled measurements.

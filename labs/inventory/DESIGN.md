# Cedarline Supply

A stock sheet for reservations and warehouse commands.

## Design

- Steel-teal accents on warm neutral surfaces. Tabular quantities, ruled rows and compact metadata carry the hierarchy.
- Warehouse, SKU and reservation views retain their independent controls. Wide tables scroll locally; command panels stack.
- On-hand, reserved and available quantities stay distinct. Rejections and stale reads use explicit text rather than color alone.

The interface exposes one synthetic writer and consumed projection, not a deployed warehouse management system.

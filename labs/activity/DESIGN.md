# Commonfield Dispatch

A public reading room with caller-selected profiles.

## Design

- Warm paper and restrained plum actions. Serif reading hierarchy contrasts with plain system controls.
- Feed, article, profile and logged activity use reading measures rather than dashboard cards. Dense metadata wraps separately.
- Read, like and follow actions keep native controls and explicit state. Profile selection never implies sign-in.

All content and activity are public synthetic fixtures. No private feed or identity service is deployed.
